# 🗺️ Mastering Markdown: A Convivial Writing Guide

Welcome to our shared digital sandbox. In this course, we reject heavy, automated text layout platforms that track your data. Instead, we use **Markdown**—a lightweight, plain-text language that honors digital sovereignty, runs on any hardware, and preserves student usage privacy.

This guide provides the core syntax parameters required to author your weekly repository lab evaluation reports.

---

## 🛠️ Core Syntax Reference

### 1. Headers & Hierarchy
Structure your structural forensics cleanly using the hash (`#`) symbol. Always separate headers from prose text with a blank line.

```text
# Title of Document (Use once per file)
## Major Theoretical Section (e.g., Theoretical Context)
### Subsection Analysis (e.g., Auditing Proxy Analytics)
#### Minor Sub-point
```

### 2. Text Emphasis & Style

Guide your reader's eye using subtle emphasis blocks.

- **Bold Text:** Wrap your target words in double asterisks: `**Ivan Illich**` renders as **Ivan Illich**.
* *Italic Text:* Wrap your text in single asterisks: `*intellectus*` renders as *intellectus*.
- ~~Strikethrough:~~ Wrap your text in double tildes: `~~telemetry~~` renders as ~~telemetry~~.

### 3. Structural Lists

For splitting out comparative diagnostic metrics or tracking variables.

**Unordered Block Layout:**

```text
* First core criterion of a Radical Monopoly
* Second core criterion of a Radical Monopoly
```

- First core criterion of a Radical Monopoly
- Second core criterion of a Radical Monopoly

**Ordered Pipeline Layout:**

```text
1. Initialize local Git workspace repository.
2. Execute standard baseline configuration checks.
```

1. Initialize local Git workspace repository.
2. Execute standard baseline configuration checks.

### 4. Interactive Links and Anchors

To reference open-source libraries or documentation securely, use standard link variables: `[Visible Text](URL)`.

- **Example:** `[Access Ivan Illich via Internet Archive](https://archive.org/details/toolsforconvivia0000illi)`
- **Renders as:** [Access Ivan Illich via Internet Archive](https://archive.org/details/toolsforconvivia0000illi)

### 5. Code Enclosures & Blockquotes

When copying terminal streams, system log events, or calling out foundational quotes.

- **Inline Elements:** Use single backticks (`) to highlight a standalone configuration key, file name, or tracking interval like `labs/02-nudge-simulation.html`.
- **Fenced Code Blocks:** Use triple backticks (```) to isolate multiline script logs or plain text diagrams so your editor doesn't warp line breaks.

> **Theoretical Pillar Note:** Use a greater-than sign (`>`) to display a structural blockquote. This is reserved for emphasizing core text extracts from our course readings, such as Audrey Watters or Cathy O'Neil.
