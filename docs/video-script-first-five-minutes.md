# Video Script: Your First Five Minutes (Screen Capture Walkthrough)

Target length: ~5 minutes. Record at whatever pace feels natural — it's
fine to run a little long. Narration is in plain text; on-screen actions
are in [brackets].

---

**[0:00 — Talking head or title card]**

"Hi, this is a quick walkthrough to get your course repository set up.
By the end of this video, you'll have made your first real commit and
seen it show up on GitHub. It takes about five minutes, and you don't
need any prior experience with this."

---

**[0:20 — Screen: email inbox showing the GitHub invitation]**

"First, check your email for an invitation from GitHub — it'll have a
subject line like 'You've been invited to a repository.' Click Accept.
If you don't see this, email me and I'll resend it."

[Click through accepting the invite, show landing on the repo page]

"This is your repository. Only you and course staff can see this page
— it's private, so don't worry about anyone else stumbling onto it."

---

**[1:00 — Screen: desktop.github.com download page]**

"Next, download GitHub Desktop — this is a free app that handles Git
for you without needing the command line. Install it like any other
app."

[Show install, then opening the app]

"Sign in with the same GitHub account that got the invitation."

---

**[1:45 — Screen: GitHub Desktop, File menu]**

"Now click File, then Clone Repository."

[Click through: File → Clone Repository]

"You should see your repo in this list — it'll be named
'impacts-computing-' and then your username. Select it, choose
anywhere on your computer to save it — your Desktop is fine — and
click Clone."

[Show the clone completing]

---

**[2:30 — Screen: Finder/File Explorer, opening the cloned folder]**

"Once that's done, open the folder it just created. You'll see a
README file in here — go ahead and open that in any text editor."

[Open README.md in TextEdit/Notepad or similar]

"Add one line anywhere — literally just type your name. This is a
throwaway test, not real coursework, so it doesn't matter what you
write."

[Type a line, save the file]

---

**[3:15 — Screen: back in GitHub Desktop]**

"Now switch back to GitHub Desktop. See how it shows your change on
the left? Down here at the bottom, type a short summary — something
like 'testing my setup' — and click Commit to main."

[Show typing summary, clicking Commit to main]

"Then click Push origin up here at the top. This uploads your change
to GitHub."

[Click Push origin, show it completing]

---

**[4:00 — Screen: browser, refreshing the repo page on github.com]**

"Let's go check it worked. Back on your repository page on github.com,
hit refresh."

[Refresh page, scroll to show the README with the new line]

"There's your change. That's the entire loop you'll use all semester:
edit a file, commit, push, and it shows up here. Every assignment this
semester works exactly like this."

---

**[4:30 — Talking head or title card]**

"That's it for the required part. The written guide has a couple of
optional steps after this — setting up your name and email properly,
and what to do each week when new material comes out — but you've
already done the hard part. If anything doesn't work the way it did in
this video, just email me. There's no bad question here — most of this
class has never used Git before, so you're not behind."

[End card: instructor email / office hours info]
