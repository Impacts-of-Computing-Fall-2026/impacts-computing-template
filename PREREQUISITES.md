# ⚡ Prerequisites: Setting Up Your Convivial Workspace

Before our Day 1 live synchronous session, you must configure your local workspace environment. Arriving with these lightweight tools prepared ensures we can immediately bypass institutional trackers and begin building our decentralized learning network together.

---

## 🏗️ Step 1: Create a GitHub Account and Submit Your Username

We use GitHub as an asynchronous post office to share text repositories.
1. Go to [GitHub.com](https://github.com/) and register a free account.
2. **Privacy Option:** You are welcome to use a pseudonymous or alternative handle for this course if you wish to protect your student usage data from public search indexing.
3. **Submit your GitHub username** via the pre-semester form (link posted on Brightspace / emailed by the instructor). Your private course repository is created from this username — without it, you won't receive your repository invitation before Day 1.

---

## 💻 Step 2A: Desktop & Laptop Setup

Git is the engine that tracks text changes locally on your computer. Install it based on your operating system:

### 🍏 For macOS Users
1. Open your terminal application (Press `Cmd + Space`, type `Terminal`, and hit Enter).
2. Type the following command and hit Enter:

    git --version

3. If it is not installed, a prompt will automatically pop up asking you to install **Xcode Command Line Tools**. Confirm the installation and follow the on-screen prompts.

### 🐧 For Ubuntu / Linux Users
1. Open your terminal (`Ctrl + Alt + T`).
2. Run the standard installation command:

    sudo apt update && sudo apt install git -y

### 🪟 For Windows Users
1. Download the lightweight standalone installer from [Git for Windows](https://gitforwindows.org/).
2. Run the `.exe` file. Accept the default options during setup, ensuring that **Git Bash** is selected. You will use the Git Bash terminal for all course operations.

### 🧬 Verification Task
To confirm your desktop environment is ready, open your terminal (or Git Bash on Windows) and execute:

    git --version

If the screen prints a version number (e.g., `git version 2.x.x`), your machine is officially configured.

Also install [GitHub Desktop](https://desktop.github.com) — most students will use this rather than the raw terminal commands above for day-to-day coursework. See the Student Guide for the full walkthrough.

## 📱 Step 2B: Alternative Mobile Setup (If You Do Not Have a Laptop)

If you are navigating this course using a mobile device or tablet as your primary workspace, you can fully interact with our text network without a computer terminal. This setup ensures that high hardware costs do not become an invisible barrier to learning. Note that the Student Guide's step-by-step instructions are written for GitHub Desktop on a computer — if you're on mobile full-time, email the instructor and we'll work through the equivalent steps together.

### 🤖 For Android Users
1. Download the official **GitHub** app from the Google Play Store.
2. *Optional:* For a completely open-source environment, download **Termux** from F-Droid to simulate a full Linux command-line terminal directly on your mobile device.

### 🍏 For iOS (iPhone/iPad) Users
1. Download the official **GitHub** app from the Apple App Store.
2. *Recommended:* Download **Working Copy** from the App Store. This is a powerful, mobile-native Git client that serves as an ultra-lightweight text editor and repositories folder.

### 🗺️ Mobile Verification Task
1. Open your mobile GitHub app and log in using your account handle.
2. Check that you've received and accepted your repository invitation (search for `impacts-computing-<your-username>` under your repositories — it will only be visible once you're logged in, since it's private).
3. If you can see your own private repository and its module folders on your device screen, your mobile node is officially live.
